The page's request builder (peakToBackendSpec in templates/index.html) sends amplitude_min: 0 and never an amplitude_max; a free ds_g peak gets no default centre window in fitting._make_peak_params. lmfit's differential_evolution refuses any varying parameter with an open bound, so every ordinary request for that method returned HTTP 422 "Fit failed".
