WHAT IS CLAIMED, AND WHAT IS NOT
Claimed: every random draw is a pure function of the request; LM and Nelder-Mead results are byte-identical press to press; the seed value is pinned.
NOT claimed: byte-identical Trust-Region (least_squares). Evidence in CLAUDE.md: OpenBLAS ddot gives two values for the same vector at different memory alignments; inside scipy's _lsq/trf.py `norm` is the first call to return different output for identical input; the iteration amplifies it to ~1e-4 relative in an area. Measured on 202 committed targets x 5 presses, before -> after seeding: Trust-Region byte-identical on 51 -> 146 targets; > 1 pp between presses on 8 -> 0; > 0.01 pp on 14 -> 1 (0.33 pp); LM byte-identical 145 -> 202.
