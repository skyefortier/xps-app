# Scientific repair and validation report

Date: 2026-09-08. Work is isolated on `codex/scientific-code-audit-2026-09`, following audit commit `5b43cd0`. The deployed checkout, production branch and running services were not changed. The original audit and its baseline measurements remain in `docs/audit-2026-09-08.md` and its companion directory.

## Repair scope

This is an incremental repair of the existing architecture, not a rewrite or visual redesign. It addresses the audit's numerical, inference, application-state and persistence findings, and adds regression checks that exercise the original failures.

* DS+G convolution now integrates a symmetric Gaussian displacement kernel against the analytic core, normalizes at the continuous center and handles even/odd grids consistently. LA convolution evaluates its analytic continuation outside the displayed window and normalizes continuously. Browser and Python calculations agree in the tested cases. LA still uses the app's channel-spacing convention for its broadening parameter; equivalence to proprietary CasaXPS code is not established.
* Linked Gaussian/Lorentzian/GL component constraints enforce analytic full-domain area ratios when widths differ. Unsupported independent-shape asymmetric links fail explicitly. Shared-shape links retain their scale-ratio convention. Positive-alpha DS still does not have a finite infinite-domain area.
* Finite-window area standard errors use the full fitted covariance and numerical derivatives of the actual integral, including dependent parameters. These remain conditional on the chosen background/model and lmfit's covariance scaling. DS+G effective width is measured at half the actual asymmetric maximum.
* Supplied inverse-sigma weights reach least-squares fitting. The ordinary added-peak F statistic is retained only as a descriptive diagnostic, without an uncalibrated significance probability. MCR retains the uncentered signal when estimating reconstruction rank. Invalid or inadequate Bayesian sampling settings are rejected; missing sampling/evidence diagnostics cannot be labeled reliable.
* Local fitting now descends, checks convergence and physical bounds, and preserves prior state on failure. Its unweighted residual variance is identified explicitly. Manual and automatic backend fits capture request inputs, reject stale responses and use the server's fitted arrays/statistics. Charge refinement transforms the frozen fit grid consistently.
* Model/background/constraint edits invalidate old diagnostics. Find Peaks replacement clears the previous fit. Batch fitting copies endpoint averaging and scaled manual anchors, handles failures explicitly and detects intervening tab changes.
* Saved projects retain precise fitted arrays, parameter uncertainty, objective identity, settings and software provenance. Spectrum exports keep arrays and diagnostics from the same accepted fit. Table exports refuse stale/incomplete results. Backend identity comes from the fitting response; an unknown legacy fit is not assigned the current software version.
* When older or unknown-version DSG_LA, LACX or Voigt fits are loaded, their original fitted arrays, peaks, settings, charge shift and manual anchors are retained in a historical record. The app requires a new fit for current quantitative results. Same-version results remain active. Historical records survive both project and spectrum save/load cycles.
* Async analysis uses two file-lock leases shared across processes using the same upload directory. Excess requests receive HTTP 429 and Retry-After. Leases release on normal completion, failures and process exit; consequential request iteration counts are bounded. This is an application-level resource limit, not a production capacity/load certification.

## Independent evidence

The original eight application counterexamples and all 17 independent science checks pass after repair. The nine statistics checks pass, including analytical weighted amplitude recovery and rank-one/rank-two reconstruction examples. Additional regressions compare the DS+G zero-asymmetry limit with SciPy's Voigt function and a difficult asymmetric case with independent adaptive integration.

Integration uncovered an additional replicated-evidence bug: candidate free energy used every repeated run, but its error estimate used only the first run's within-chain error. In the required U4f case, the evidence gap of 25.300 exceeded the old error comparison of 15.699, giving an unjustified resolved label. Including all contributing errors raises that comparison to 59.385 and correctly leaves selection unresolved. Controlled counterexamples cover large or missing later-run errors and missing ESS. The original required unresolved expectation was preserved, and its error-bound assertions strengthened.

The 29 existing U4f reference refits all converge. Substituting only the corrected LA evaluator into the baseline engine reproduces the changed fit parameters, isolating the cause. Largest differences from the unchanged historical fixture are 0.0043 eV in center, 0.83% in width, 0.89% in amplitude, 0.67% in area and 0.33% in reduced chi-square. The revised compatibility tests check independent profile evaluation, objective improvement from the corrected starting model and exact constraints, plus explicitly documented migration limits. Those limits are engineering checks, not experimental error bars. The measurements and retained fixture identity are recorded in `repairs-2026-09-08/u4f-numerical-migration.json`.

The 72-fit background/window/initialization/noise sensitivity study was repeated. All fits converge, but the previously measured scientific sensitivity remains: free-width component-area errors reach approximately 9.49% with the known background, 23.30% with estimated Shirley, and 76.33% with a deliberately misspecified linear background. Fixing the correct widths reduces these errors in this constructed example. Software corrections do not resolve model identifiability or validate a chemical assignment.

## Experimental compatibility

All 59 supplied files from Runs 5–9 remain readable and unchanged. They contain 1,143 spectrum records, 964 distinct raw-array pairs and 876 saved fits. The same 276 complete records can be replayed; after numerical correction, 65 differ from their saved curves by more than 1% of peak height, versus 55 under the baseline. A larger mismatch count is expected when preserving historical curves while changing an erroneous evaluator; it is not a measure of which fit better describes the experiment. The 553 legacy incomplete grid/background tuples remain a limitation.

Experimental originals and detailed private inventories stay outside Git. No new experimental arrays were uploaded or committed. Saved historical fits are comparison evidence, not ground truth. Corrected asymmetric profiles can require refitting, with acquisition conditions, energy referencing and an independently reviewed comparison fit used to assess interpretation.

## Performance

Correctness has a measurable cost. A representative C1s analysis of an existing repository anchor (four candidates/four refits) took 67.3 seconds with the corrected profile versus 48.5 seconds with the baseline profile, approximately 39% longer. Winner, conditional status, survivor count and warnings were unchanged; neither run truncated or failed to converge. This is one measured case, not a general latency prediction.

An independently checked FFT path avoids a much worse broad-Gaussian/narrow-core cost: a 701-channel extreme DS+G evaluation fell from 27.3 ms with direct quadrature to 0.35 ms. Normal 301-channel DS+G and LA evaluations measured approximately 0.370 ms and 0.075 ms, versus 0.157 ms and 0.023 ms in the baseline. Browser calculations and adaptive integration remain agreement checks, not performance targets.

## Remaining scientific work

These tests establish specific calculation and state contracts. They do not establish universal peak-recovery accuracy, interval coverage, Bayesian evidence calibration, correctness of every reference value, proprietary software equivalence, or an absolute quantification method for the user's materials. Counts/CPS variance and preprocessing metadata, background sensitivity, prior sensitivity, RSF/transmission assumptions and instrument import comparisons still require experimental evidence. The Shirley iteration controls and separate preview/backend background implementations also need a dedicated parity assessment beyond the background cases already tested.

Visual redesign should follow this numerical/compatibility checkpoint. A useful next UI pass would expose the fitting window, background assumptions, constraint choices, residuals and unavailable uncertainty without implying that a low residual proves a chemical model.
